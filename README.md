## 搬瓦工 10Gbps 是什么带宽？先把这个数字搞清楚

它指的是 VPS 节点到机房交换机之间上行链路的速率上限，最高 10Gbps。写 10G 不等于随时跑满 10G，实际速度受线路、时段和并发影响。

背景简单交代：搬瓦工 2019 年 2 月开始接入 10Gbps CN2 GIA 企业级带宽，当时主要面向跨境电商业务。现在撑起这个数字的，是部署在洛杉矶 DC6、DC9 两个机房的 8 条 10GbE CN2 GIA/CTGNet 专线，同时与 Google 等本地运营商直接对等互联。

名字里的"E"也有讲究：CN2 GIA-E 全称是 CN2 GIA ECOMMERCE（电商专线），最初是中国电信为跨境电商设计的线路规格，回程对三网都做了优化——电信走 CN2 GIA，联通和移动由中国电信提供企业级专线对接。市面上打着 CN2 GIA 旗号的商家，大多只给 1Gbps 上行；搬瓦工把上限拉到 10Gbps，更实际的意义是晚高峰有余量，不容易被挤扁。

## 10Gbps 实测能跑多少？纸面参数和实际速度的差距

社区里有用户公开的实测记录：本地 Speedtest 到服务器能跑到 6Gbps 左右；跨国到中国大陆，稳定在 500Mbps～1Gbps 之间。晚高峰延迟大致 120～160ms，丢包接近零。

这个差距很正常。跨境链路的瓶颈在出口和回程路由，不在机房内网。你从大陆家宽去拉一台美国 VPS 上的文件，决定速度的是跨境段；10Gbps 端口保证的是机房内侧不被卡住——比如多个用户同时拉流、CDN 回源、服务器之间对拷数据。

入门的 2.5Gbps 套餐，实测通常在 500Mbps～2Gbps 之间浮动，受时段、测试节点和你本地宽带影响。对个人使用来说，这个数字已经绰绰有余。

一句话判断：人在大陆访问，追求稳定低丢包，2.5Gbps 档完全够用；10Gbps 的价值只在服务器侧的高并发传输场景里兑现。

## 谁真正需要 10Gbps 套餐？

四类场景值得上 10G（或至少 5G）端口：

1. **CDN 节点 / 大文件分发**：640G 套餐月流量 10TB 起，按每次传 1GB 文件算够传一万次，10Gbps 端口撑得住几百个并发连接。
2. **流媒体服务**：同时给多路用户推流，带宽余量直接决定卡不卡。
3. **跨境电商与高并发 API**：请求密集型业务，吞吐不够时排队的是用户。
4. **开发测试与数据同步**：频繁推大镜像、同步数据库，10Gbps 能把等待时间压得很低。

反过来说，这几类人不用看 10G：

- 个人博客、企业官网：1～2Gbps 已经过剩，该关心的是线路质量。
